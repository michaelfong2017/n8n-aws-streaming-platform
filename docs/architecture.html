Overview

Complete infrastructure for streaming from OBS to AWS IVS, with automated frame sampling via Lambda and analysis through n8n running on EKS.

✅ Optimized for Hong Kong
  • Singapore region (ap-southeast-1) - 36ms latency
  • ARM64 (Graviton2) everywhere - 20% cost savings
  • Auto-scaling n8n (1-3 pods)
  • Cost: ~$155-160/month

Quick Start

1. Deploy Infrastructure

cd terraform
terraform init
terraform apply

2. Deploy Applications with Helm

cd ../helm/n8n-streaming-platform

# Update dependencies
helm dependency update

# Get values from Terraform
CLUSTER_NAME=$(cd ../../terraform && terraform output -raw eks_cluster_name)
ALB_ROLE_ARN=$(cd ../../terraform && terraform output -raw eks_alb_controller_role_arn)

# Install
helm install n8n-streaming-platform . \
  -n n8n-streaming \
  --create-namespace \
  --set global.clusterName=$CLUSTER_NAME \
  --set aws-load-balancer-controller.serviceAccount.annotations."eks\.amazonaws\.com/role-arn"=$ALB_ROLE_ARN

3. Configure OBS

# Get streaming credentials
cd terraform
terraform output ivs_ingest_endpoint
terraform output -raw ivs_stream_key
